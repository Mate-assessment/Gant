/** * גאנט פיילוט 67 – חיבור בין הגאנט לגיליון * ------------------------------------------------ * הקוד הזה יושב בתוך הגיליון (תוספים ← Apps Script). * הוא מאפשר לגאנט לקרוא את המפגשים, ולעורכות שיש להן את קוד העריכה * להוסיף, לערוך ולמחוק מפגשים ישירות מתוך הגאנט. * * קוד העריכה (הסיסמה) לא כתוב כאן. הוא נשמר במאפייני הסקריפט: * הגדרות הפרויקט (⚙️) ← מאפייני סקריפט ← מאפיין בשם EDIT_CODE והערך הוא הסיסמה. */ function editCode_() { return String(PropertiesService.getScriptProperties().getProperty('EDIT_CODE') || '').trim(); } const SHEET_GID = 1366039283; // הלשונית "ישיבות קוקפיט (צוות אגף)" const COLS = ['תחנה', 'תקופה', 'מעגל', 'תאריך', 'נושא במיקוד']; /* ---------- קריאה: הגאנט מבקש את כל המפגשים ---------- */ function doGet() { const sh = sheet_(); const values = sh.getDataRange().getDisplayValues(); return json_({ ok: true, rows: values }); } /* ---------- כתיבה: הוספה / עריכה / מחיקה ---------- */ function doPost(e) { let req; try { req = JSON.parse(e.postData.contents); } catch (err) { return json_({ ok: false, error: 'bad_request' }); } const code = editCode_(); if (!code) return json_({ ok: false, error: 'not_configured' }); if (String(req.code || '').trim() !== code) return json_({ ok: false, error: 'wrong_code' }); const lock = LockService.getScriptLock(); if (!lock.tryLock(15000)) return json_({ ok: false, error: 'busy' }); try { const sh = sheet_(); const all = sh.getDataRange().getDisplayValues(); const hRow = all.findIndex(r => r.some(c => String(c).trim() === 'תחנה') && r.some(c => String(c).trim() === 'תאריך')); if (hRow < 0) return json_({ ok: false, error: 'no_header' }); const head = all[hRow].map(c => String(c).trim()); const idx = COLS.map(n => head.findIndex(x => x === n || x.indexOf(n) === 0)); if (idx.some(i => i < 0)) return json_({ ok: false, error: 'no_header' }); const action = req.action; const vals = (req.values || []).map(v => String(v == null ? '' : v).trim()); if (action === 'add') { const rowNum = Math.max(sh.getLastRow(), hRow + 1) + 1; writeRow_(sh, rowNum, idx, vals); return json_({ ok: true, row: rowNum }); } const rowNum = Number(req.row); if (!rowNum || rowNum <= hRow + 1 || rowNum > all.length) return json_({ ok: false, error: 'row_changed' }); // בדיקת בטיחות: השורה בגיליון עדיין זהה למה שהעורכת ראתה const current = idx.map(i => String(all[rowNum - 1][i]).replace(/\s+/g, ' ').trim()); const expect = (req.expect || []).map(v => String(v).replace(/\s+/g, ' ').trim()); if (current.join('\u0001') !== expect.join('\u0001')) return json_({ ok: false, error: 'row_changed' }); if (action === 'update') { writeRow_(sh, rowNum, idx, vals); return json_({ ok: true, row: rowNum }); } if (action === 'delete') { sh.deleteRow(rowNum); return json_({ ok: true }); } return json_({ ok: false, error: 'bad_request' }); } finally { lock.releaseLock(); } } /* ---------- עזר ---------- */ function writeRow_(sh, rowNum, idx, vals) { idx.forEach((c, k) => { const cell = sh.getRange(rowNum, c + 1); if (COLS[k] === 'תאריך') cell.setNumberFormat('@'); // שהתאריך יישמר כטקסט (8.11) ולא יהפוך למספר cell.setValue(vals[k] || ''); }); } function sheet_() { const ss = SpreadsheetApp.getActive(); // מזהים את הלשונית לפי המספר הקבוע שלה (לא משתנה גם אם משנים את השם), ואם לא – לפי השם const sh = ss.getSheets().find(s => s.getSheetId() === SHEET_GID) || ss.getSheets().find(s => s.getName().indexOf('ישיבות') === 0); if (!sh) throw new Error('לא נמצאה הלשונית של המפגשים'); return sh; } function json_(obj) { return ContentService.createTextOutput(JSON.stringify(obj)).setMimeType(ContentService.MimeType.JSON); }
